  - `@carvalhorafael/eumilitar-tokens/spacing.json`
  - `@carvalhorafael/eumilitar-tokens/effects.json`

## Objetivo do JSON

O export JSON existe para consumers que não querem ler CSS diretamente, como:

- scripts de build;
- futuros projetos externos de tema WordPress;
- integração com toolchains adicionais;
- auditorias e transformações automatizadas.
