# Consumer Static

Consumer mínimo da biblioteca para validar uso em HTML/CSS/JS puro.

## Objetivo

Provar que a base `@eumilitar/web` funciona fora de:

- React
- Next.js
- WordPress

## Geração

```bash
npm run build --workspace=consumer-static
```

Isso gera:

- `dist/index.html`
- `dist/styles.css`
- `dist/main.js`
